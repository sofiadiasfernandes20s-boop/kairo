# Kairo

Aplicação web para organizar a rotina diária: tarefas com data, horário, duração, categoria e prioridade, além de um dashboard com o resumo do dia.

Autora: Sofia Dias – Desenvolvimento Web Front-End – FUMEC

## Como rodar

1. Instalar as dependências: `npm install`
2. Iniciar a API (JSON-Server) em um terminal: `npm run api` (http://localhost:3000)
3. Iniciar o Angular em outro terminal: `npm start` (http://localhost:4200)

Usuário de teste: `sofia@kairo.com` / senha `123456`

## Telas

- Login (`/login`)
- Cadastro de usuário (`/cadastro`)
- Lista de tarefas (`/tarefas`)
- Detalhe da tarefa (`/tarefas/:id`)
- Nova / Editar tarefa (`/tarefas/nova`, `/tarefas/editar/:id`)
- Dashboard (`/dashboard`)
